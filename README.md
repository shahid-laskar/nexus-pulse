# Nexus Pulse

You are a Principal Product Designer from Linear, Vercel, Stripe and Tailscale.

Your task is to design a world-class Network Operations Center (NOC) web application for a modern ISP.

This is NOT a coding task.

Do NOT generate React code.

Do NOT generate HTML.

Your job is to think like an experienced product designer and produce a complete UX strategy, information architecture, design rationale, and high-fidelity screen specifications that will later be implemented using React + TypeScript + Tailwind CSS v4.

You have complete creative freedom.

Do not imitate existing dashboards. Create something original while following modern SaaS UX principles.

The final product should feel like software built by Apple, Linear, Vercel, Stripe, Tailscale, Cloudflare, Datadog and Grafana—not like a traditional enterprise admin panel.

--------------------------------------------------

## Project

Design a modern ISP Network Operations Center (NOC).

The application is used by engineers monitoring and managing thousands of customers, routers, NAS devices, OLTs, switches, access points and network services in real time.

The application must prioritize speed, clarity, situational awareness and operational efficiency.

Operators should be able to understand network health within seconds.

Every interaction should reduce cognitive load.

Every screen should maximize productivity.
